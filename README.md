# Pokedex API

Projeto desenvolvido durante o **#7DaysOfCode**.

Esta é a estrutura inicial (Dia 1). O projeto evoluirá para uma API de personagens de jogos da franquia Pokémon.

## Estrutura atual

```text
pokedex-api/
├── app/
│   └── main.py
├── .venv/
├── .gitignore
└── README.md
```

## Como executar

1. Ative o ambiente virtual:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

2. Execute o projeto:

   ```powershell
   python app/main.py
   ```

Saída esperada:

```text
Hello, treinador!
```
